# StandBy for Android

充電中にスマートフォンを横向きに置くと、黒背景のスタンバイ画面を自動表示する Android アプリです。iPhone の StandBy に近い雰囲気を、Jetpack Compose と Material 3 Expressive で実装しています。

> **本物の AOD ではありません。** Android の一般アプリは画面消灯中に描画できないため、充電中は画面を低輝度で点灯したまま表示します。

## 特長

- **自動起動**: 充電中 + 横向き + 画面オフ / ロック中でスタンバイ画面を表示
- **時計 5 種**: Digital / Analog / World / Solar / Flip
- **レイアウト 3 種**: Hero / Split / Stack
- **ウィジェット**: 天気（Open-Meteo）、音楽（MediaSession）、バッテリー。3 スロットに自由に配置
- **カスタマイズ**: 6 プリセット、アクセント 6 色、24 時間表示、秒表示、日付フォーマット、フォントウェイト
- **OLED 向け**: 純黒背景、任意の明るさ、減光、赤色ナイトモード、ピクセルシフト
- **クイックコントロール**: スタンバイ画面を長押しで明るさ・減光・プリセットを変更
- **ジェスチャー**: タップで減光復帰、下スワイプ / 戻るで終了
- **診断画面**: 権限状態、端末情報、アプリ内ログ、前回のクラッシュログを確認
- **QS タイル**: クイック設定からスタンバイを起動
- **HyperOS 導線**: 自起動・バッテリー制限・ロック画面/ポップアップ権限の設定画面へ案内

## インストール

1. [Releases](../../releases) から最新の `app-release.apk` をダウンロード
2. 端末で「提供元不明のアプリ」を許可してインストール
3. アプリを開き、オンボーディングの案内に従って権限を許可

ADB でインストールする場合:

```bash
adb install -r app-release.apk
```

## 初期設定

自動起動には次の権限・設定が必要です。

1. **通知** — 常駐通知と起動の案内
2. **他のアプリの上に重ねて表示** — バックグラウンドからスタンバイを開く主経路
3. **バッテリー最適化の解除** — 画面オフ中も監視を続ける
4. **全画面インテント通知**（任意） — ロック画面から直接表示する補助経路
5. **通知アクセス**（任意） — 音楽ウィジェットの MediaSession 取得
6. **位置情報**（任意） — 現在地の天気。未許可なら東京にフォールバック

### Xiaomi / HyperOS

HyperOS はバックグラウンド起動とロック画面表示の制限が強く、標準 Android の権限だけでは自動表示が止まることがあります。アプリのホーム画面・診断画面・オンボーディングに設定への導線があります。

1. **自動起動** — アプリ情報 → 自動起動 をオン（「自起動」ボタン）
2. **バッテリー** — 省電力設定を「制限なし」に変更（「バッテリー」ボタン）
3. **権限エディタ** — 「権限エディタ」ボタンから次を許可
   - ロック画面に表示
   - バックグラウンドでポップアップ表示
   - 必要に応じて「他のアプリの上に重ねて表示」
4. **通知** — 常駐通知と起動案内を許可
5. **全画面インテント通知** — 設定 → アプリ → 特殊なアプリのアクセス → 全画面インテント を許可

HyperOS のバージョンによって項目名・画面が変わるため、直接開けない場合は アプリ情報 → 該当項目 から手動で設定してください。設定後は一度アプリを再起動するか、端末を再起動すると反映が安定します。

> HyperOS の省電力が強い場合、画面オフ中はスタンバイ画面の起動だけ行われ、画面は点かないことがあります。その場合は電源ボタンでロック画面を点けるとスタンバイが表示されます。自動点灯は端末ポリシー上保証されません。

## 使い方

1. 充電器に接続する
2. 端末を横向きに置く
3. 画面がオフ、またはロック中ならスタンバイ画面が表示される
4. タップで減光から復帰、長押しでクイックコントロール
5. 下スワイプまたは戻るで終了（縦向き・充電解除でも終了）

自動表示は「充電中 + 横向き + 画面オフ/ロック中」に限定しています。ホーム画面などロック解除中は表示せず、表示中にロックを解除するとスタンバイ画面は閉じます。

## ビルド

必要なもの:

- JDK 21
- Android SDK Platform 37
- Android SDK Build-Tools 36.0.0

```bash
./gradlew :app:assembleDebug
```

APK は `app/build/outputs/apk/debug/app-debug.apk` に出力されます。

### 単体テスト

```bash
./gradlew :app:testDebugUnitTest
```

`TriggerEngine` の状態遷移、設定 JSON のラウンドトリップ、正規化、プリセット適用、ウィジェットスロットの重複防止をテストしています。

### Release ビルドと署名

`keystore.properties` がリポジトリ直下にある場合、Release はその鍵で署名されます。ない場合は debug 鍵で署名されます（ローカル確認用）。

```properties
storeFile=/absolute/path/to/release.keystore
storePassword=...
keyAlias=...
keyPassword=...
```

```bash
./gradlew :app:assembleRelease -PversionName=0.1.0 -PversionCode=1
```

CI の Release では次の GitHub Secrets を使用します。

- `KEYSTORE_BASE64`
- `KEYSTORE_PASSWORD`
- `KEY_ALIAS`
- `KEY_PASSWORD`

キーストアは絶対にリポジトリへコミットしないでください。生成後は安全にバックアップしてください。

## トラブルシューティング

### 充電しても自動起動しない

- 「自動起動」がオンか確認
- 通知・重ねて表示・バッテリー最適化解除を確認
- HyperOS の自起動 / バッテリー制限を確認
- 横向き判定は 1.5 秒のデバウンスがあります。少し待ってください
- 画面オン・ロック解除中は自動表示されません（ロック画面専用）。ロックを解除すると表示中のスタンバイ画面も閉じます
- 開発者オプションの「充電中は画面をスリープしない」がオンだと、画面が消えず自動起動しません。オフにしてください
  - 確認コマンド: `adb shell settings get global stay_on_while_plugged_in`（`0` 以外なら該当）
- アプリを強制停止した場合、再起動するまで自動起動しません
- 診断画面のログで「トリガー」の状態を確認

### 天気が「未取得」になる

- ネットワーク接続を確認
- 位置情報を許可するか、未許可のまま東京の天気を使用
- 天気は 30 分ごとに更新されます。ホームの天気カードをタップすると手動更新できます

### 音楽が表示されない

- 通知アクセスが許可されているか確認
- 音楽アプリが MediaSession を公開しているか確認
- 通知の内容は読み取りません。MediaSession のメタデータのみ使用します

### 画面が暗い / 明るさが戻らない

- 減光までの時間と減光時の明るさを確認
- スタンバイ画面をタップすると減光から復帰します

## 構成

```
app/src/main/java/jp/yukirawa/standby/
├─ MainActivity.kt          ホーム / カスタマイズ / 診断 / オンボーディング
├─ MainViewModel.kt
├─ data/                    設定・天気・音楽・バッテリー・診断ログ
├─ model/                   設定モデル・プリセット
├─ service/                 常駐サービス・通知・起動戦略・QS タイル
├─ standby/                 スタンバイ画面・時計・ウィジェット
├─ trigger/                 向き・画面状態・純 Kotlin トリガーエンジン
├─ permissions/             権限確認と設定画面遷移
├─ di/                      手動 DI（AppContainer）
└─ ui/theme/                配色・テーマ
```
