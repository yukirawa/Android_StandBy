# プライバシーポリシー

StandBy（`jp.yukirawa.standby`）は、個人利用と GitHub 配布を前提とした Android アプリです。解析 SDK・広告 SDK・アカウント機能は含みません。

## 収集する情報

アプリは外部サーバーへ個人情報を送信しません。ただし、天気取得のために次の情報を利用します。

- **位置情報（任意）**: 現在地の緯度・経度を Open-Meteo（`https://api.open-meteo.com`）へ送信し、天気を取得します。
- 位置情報を許可しない場合は、東京の座標を固定で使用します。

## 端末内に保存する情報

次の情報は端末内にのみ保存され、外部へ送信されません。

- アプリ設定（時計・レイアウト・色・明るさ・ウィジェット配置など）
- 天気のキャッシュ（`filesDir/weather_cache.json`）
- 診断ログ（アプリ内メモリ。アプリを終了すると消えます）

## 通知アクセス

音楽ウィジェットのために通知アクセスを利用しますが、**通知の内容は読み取り・保存・送信しません**。MediaSession から取得した曲名・アーティスト・アルバムアート・再生状態のみを画面表示に使用します。

## 権限

| 権限 | 用途 |
|---|---|
| 通知 | 常駐通知とスタンバイ起動の案内 |
| 他のアプリの上に重ねて表示 | バックグラウンドからスタンバイ画面を開く |
| バッテリー最適化の解除 | 画面オフ中の監視を継続 |
| 全画面インテント | ロック画面からの表示フォールバック |
| 通知アクセス | 音楽の MediaSession 取得 |
| 位置情報 | 現在地の天気取得（任意） |
| フォアグラウンドサービス | 充電・画面・向きの監視 |
| 起動完了 | 再起動後の監視サービス復帰 |

## 第三者サービス

- **Open-Meteo** — 天気データ取得。利用時は Open-Meteo の利用規約・プライバシーポリシーが適用されます。

## 変更

本ポリシーを変更する場合は、このファイルとアプリの更新で通知します。
